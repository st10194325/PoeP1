# PoeP1
Part1
AFTER EXECUTING THE APP
1 Main Menu:
On the homepage, there is  three buttons:
-Report Issues: Click to report an issue (functional).
-Local Events and Announcements: Disabled for now.
-Service Request Status: Disabled for now.

2 Report an Issue Button:
Click Report Issues to open the reporting page.
Fill in the following:
*Location: Enter the issue location (text field).
*Category: Select from dropdown (e.g., Sanitation, Roads, Utilities, Other).
*Description: Type details in the text area.
*Media File: Click to upload an image or document (optional).

Click Submit to save the issue (success message appears).
Click Back to Menu to return to the homepage.

View Feedback:
After submitting, a success message appears on the main menu "issue reported successfully!"
